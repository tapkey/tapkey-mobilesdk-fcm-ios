# Tapkey MobileSDK for iOS: Firebase Cloud Messaging

Push notifications for the Tapkey Mobile SDK, through Firebase Cloud
Messaging. It is a package of its own because it depends on Firebase. See
[Push Notifications](https://developers.tapkey.io/mobile/ios/keep_up_to_date/#push-notifications).

## Requirements

Add this package next to `tapkey-mobilesdk-ios`, and set that package up as its
README describes, including `-ObjC`.

## Versions

Each version pins the same version of `tapkey-mobilesdk-ios`; the package
resolver updates them together. The tags are the same as those of
`tapkey-mobilesdk-ios`.

Firebase: 10.24 or later, below 11.
